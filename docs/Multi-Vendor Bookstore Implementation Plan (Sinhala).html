02 දත්ත සමුදාය සැලැස්ම (Multi-Vendor Database Schema)

පද්ධතියේ සියලුම පොත් එකම Master Catalog එකක තබා, සාප්පුවල තොග සහ මිල වෙන වෙනම කළමනාකරණය වන අයුරින් පහත වගු සැකසේ:

වගුව (Table) ප්‍රධාන තීරු (Columns) කාර්යභාරය (Purpose)
books (Master Catalog) id, isbn, title, author, category, tags ලංකාවේ සියලුම පොත්වල පොදු තොරතුරු (Universal ISBN record).
bookstores id, name, location (Point 4326), phone, rating ජාලගත වී ඇති සියලුම හවුල්කාර සාප්පුවල GPS Coordinates සහ විස්තර.
store_inventory id, store_id (FK), book_id (FK), price, stock_quantity එක් එක් සාප්පුව සතු පොත් පිටපත් ගණන සහ විකුණුම් මිල.
orders id, customer_name, assigned_store_id, is_routed, status පාරිභෝගිකයාගේ ඇණවුම, භාරගත් සාප්පුව සහ මාරු වූ තත්ත්වය.

03 Smart Out-of-Stock Auto-Routing තාක්ෂණික සූත්‍රය

පාරිභෝගිකයා තෝරාගත් සාප්පුවේ තොග 0 වූ විට ක්‍රියාත්මක වන PostGIS Geodesic Query එක: 

-- පාරිභෝගිකයාගේ GPS ස්ථානයට ළඟම, තොග ඇති සාප්පු තේරීම
SELECT 
    s.id AS store_id,
    s.name AS store_name,
    inv.price AS book_price,
    ROUND((ST_Distance(s.location, ST_MakePoint(:user_lng, :user_lat)::geography) / 1000)::numeric, 2) AS distance_km
FROM bookstores s
JOIN store_inventory inv ON s.id = inv.store_id
WHERE inv.book_id = :requested_book_id
  AND inv.stock_quantity > 0
  AND s.is_active = TRUE
ORDER BY distance_km ASC
LIMIT 3;
